# Sources and attribution

## Reference basis

This skill uses the official **System Reference Document 5.2.1** as its public D&D rules and terminology baseline:

- [SRD v5.2.1 landing page](https://www.dndbeyond.com/srd)
- [SRD v5.2.1 PDF](https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf)
- [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/legalcode)

The operational guidance in this skill is an original analysis of table-ready prose. The examples are original and do not reproduce passages from published adventures, setting books, bestiaries, or other sourcebooks.

Use only terminology and material available in the SRD or supplied by the user. A named D&D setting, character, faction, deity, location, or other non-SRD element in a request may be preserved as user-supplied context; this skill does not provide additional canon about it.
