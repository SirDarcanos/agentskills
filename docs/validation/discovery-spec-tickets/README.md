## Reproduce safely

From repository root, Python 3.9+ syntax (executed on Python 3.14.7/macOS):

```sh
PYTHONDONTWRITEBYTECODE=1 python3 docs/validation/discovery-spec-tickets/run_fixture.py /tmp/discovery-ticket-replay
PYTHONDONTWRITEBYTECODE=1 python3 docs/validation/discovery-spec-tickets/check.py /tmp/discovery-ticket-checks
```

Choose **new**, nonexistent output directories; scripts refuse to overwrite evidence. Fixture replay is not a new agent walkthrough. No network or installation is required. Retained `results/` are intentional executed evidence, not incidental build output. Source artifacts retain their own digests; later report/check additions do not rewrite that historical execution pin.
