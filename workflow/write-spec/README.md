# Write Spec

Express agreed behavior with rationale, exclusions, accepted limitations and verifiable acceptance IDs. Start at [SKILL.md](SKILL.md) with an ordinary request, existing agreement or bounded handoff; no Shape Work session is required. New consequential commitments remain draft until approved.

Reuse existing authoritative specs and current findings. Small changes can stay briefs; tracker publication is optional, separately authorized and read back with the target's mapped spec role. Publication, product approval and technical readiness are distinct. Standalone use stops before tickets or implementation.
