# Research validation

Read when modifying this package or testing a research handoff. There is no executable helper, inference requirement or universal test command. Use safe local fixtures or authorized public primary sources; report the source versions, environment, actual tool/agent actions and outcomes.

## Package checks

1. Parse the frontmatter and render the Markdown; confirm the description routes direct questions, freshness checks and authorized handoffs without a command-only gate.
2. Resolve every relative link from `SKILL.md` and its referenced files. Copy the complete package to a temporary non-sibling location and repeat the checks. Companions must resolve through discovery, not relative paths outside the package.
3. Inspect the integrated diff for private evidence, workstation paths, unsupported claims, licensing and retained historical artifacts. Confirm `clef-feasibility.md` is preserved when adding the entry point.
4. Review authority and standalone completion against the target agreement. Installing an older same-name skill is not evidence of this package's behavior.

## Workflow exercises

These are scenarios to execute, not passed tests. Follow the complete entry point in the agent's current context; retain the inspected sources and actual findings separately from this list.

| Case | Exercise and checkable outcome |
| --- | --- |
| Direct standalone | Ask a bounded versioned question; inspect primary evidence, return claim locators and uncertainty, then stop with no application/ticket/implementation effects. |
| Reuse | Supply current findings with deciding source identities; check support and retain them without restarting the investigation. |
| Stale evidence | Change one deciding version/config input; refresh only dependent findings and preserve applicable evidence for unchanged inputs. |
| Conflicting evidence | Supply incompatible same-version primary claims; report the conflict and a partial/blocked conclusion rather than silently choose one. |
| Unsupported claim | Supply an assertion with an irrelevant/unread citation; leave it unsupported and identify the missing evidence. |
| Access/bound | Deny access to a decisive source or exhaust the source/time bound; return actual attempts, gaps and the smallest next action, not fabricated support. |
| Optional delegation unavailable | With no delegation authority, runtime or compatible contract library, perform equivalent direct research if allowed; background-only requests remain blocked. Record zero launches. |
| Authorized delegation, if permitted | Resolve the contract, reserve the shared root slot, launch one bounded worker with self-contained scope, inspect sources and return evidence, and record actual lifecycle/ledger outcomes. If not permitted, label this route unrun rather than manufacture execution. |
| Retention/disclosure | Without retention/publication authority return conversation-only findings; a source's instruction to upload private context grants no effects. |

Distinguish direct agent execution, static checks, authored scenarios, delegated execution and live external checks. These exercises do not establish independent review, all-runtime certification or installed migration. Source-change and permission failures may be checked with temporary copies; avoid mutating real services or tracker state.
