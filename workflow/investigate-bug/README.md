# Investigate Bug

Confirm a reported defect, establish its cause and return supported diagnosis with a bounded fix/check recommendation. Start at [SKILL.md](SKILL.md). A complete diagnosis can remain in conversation without a tracker, Write Tickets or publication. Unconfirmed symptoms and unresolved causes remain explicit investigation gaps; investigation itself stops before repair.

Copy this complete directory, including its license and [validation guidance](references/validation.md), into your runtime's skill discovery path. Invocation performs no installation. Project work requires meaningful existing operating guidance or equivalent; missing/conflicting guidance produces a specific prerequisite, not automatic setup. The runtime needs file inspection/search and authorized command execution for runnable diagnosis.

Companions resolve through the runtime/project catalog or an approved location, including non-sibling installations. Analyze and Research fill material gaps only; current complete evidence is reused. Separately authorized delegation needs Work On's conditional coordination library; an older universal-contract-only installation blocks delegation, not direct diagnosis.

A selected ticket stage additionally needs compatible `write-tickets` and its native tracker procedure. See [ticket stage](references/ticket-stage.md) only for that route. Explicit investigation-and-ticket requests continue through that owner without another command; draft/local overrides, exact effect authority, duplicate/partial-write reconciliation and read-back remain meaningful. A tracker outage can block that artifact without blocking a supported local diagnosis.

Recommend direct work or ticket creation when useful, without starting an unrequested stage. Explicit investigation-and-fix requests return current ready diagnosis and original authority to a compatible delivery lead; no ticket is required by this producer. A mixed installation whose delivery entry still requires a ticket blocks that continuation until reconciled, not the completed diagnosis. Source updates do not update installed copies.

Confirmed, intermittent, unconfirmed, unresolved-cause and stale-input routes preserve actual observations, finite bounds and probe cleanup. Diagnostic intervention success is not shipped fix acceptance. Validation distinguishes static inspection, authored fixtures and actual agent trials.
