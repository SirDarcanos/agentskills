# Acceptance First

Turn agreed cross-component behavior into executable observable examples, then implement small slices and return criterion-level evidence. Start at [SKILL.md](SKILL.md) for direct matching requests or bounded method handoffs. This method stops before independent review and final delivery acceptance.

## Install and dependencies

After approving installation:

```sh
npx skills add SirDarcanos/agentskills --skill acceptance-first
```

Copy the complete package, including its [MIT notice](LICENSE), references and scripts. Discover companions through the runtime catalog or an explicit approved location, not neighboring directories. Git writes require compatible `implementation-preflight` or a current caller-supplied result; meaning/ADR changes require `domain-modeling`; delegation or recorded-finding correction requires discovered `work-on`'s execution/repair library. Ordinary direct non-Git development needs none of these companions. Missing or ambiguous helpers block only the dependent route, without installation or legacy fallback.

Expect file inspection, authorized implementation/test writes and an executable environment appropriate to the target workflow. Missing material boundaries remain unverified; simulated passes do not certify real services. Product ambiguity goes to its owner, not a guessed assertion. No tool installation, service startup or model call is implied.

## Validate

With Python 3.9+ and no third-party dependencies:

```sh
python3 workflow/acceptance-first/scripts/check-fixture.py
```

Follow [validation](references/validation.md) for packaging and authored workflow cases. The offline synthetic fixture runs an API/workflow across a real local SQLite persistence boundary: meaningful red, two checked increments, rejection without side effects and regression sensitivity. Separate synthetic reporting cases retain ambiguous intent and unavailable payment integration as blocked/unverified. These are executable fixture results, not agent-adherence, installed-discovery or live-service trials. Installation commands have not been executed here.
