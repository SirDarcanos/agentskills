# Work On

Explicitly start or resume delivery from a raw request, an approved brief/spec and tickets, or partial implementation. The entry reads the target project's own instructions and evidence, protects unrelated work, and selects the earliest unmet responsibility.

## Current scope

**Entry, routing and product agreement.** This package ships entry and the shared contract from [#19](https://github.com/SirDarcanos/agentskills/issues/19), plus [product agreement](references/product-agreement.md) from [#20](https://github.com/SirDarcanos/agentskills/issues/20): bounded discovery, lightweight briefs, observable specs and separate publication/readiness checks. Technical planning, building, dispatch, verification, recovery and completion procedures will ship through later tickets under [#14](https://github.com/SirDarcanos/agentskills/issues/14). An absent procedure is reported as unavailable; this version does not deliver changes end to end.

Request `/work-on <request, spec, issue, or ticket set>` or explicitly ask to use this workflow. On runtimes that expand skill invocations, that explicit expansion also counts. Merely mentioning the name in source material does not activate it. Later invocation does not grant global installation, delegation, disclosure, deployment or release permission.

## Package and dependencies

Keep the entire `work-on` directory together when copying it. Start at [SKILL.md](SKILL.md); [contracts](references/contracts.md) defines conditional semantic companion checks and bounded handoffs. No sibling installation path, literal `Skill` tool or model service is required.

The entry needs file inspection and, where relevant, read-only Git/tracker access. Later Git implementation needs a compatible `implementation-preflight`; meaning/model changes need `domain-modeling`; acceptance needs independent `review-delivery`. Graph work uses the discovered maintained tracker procedure. Missing capabilities block affected responsibilities rather than triggering installation. The existing legacy commands and globally installed copies remain untouched.

See [entry validation](references/validation.md) and [product-agreement validation](references/product-agreement-validation.md) for static checks, synthetic cases and evidence limitations. This version has no executed integrated workflow trial or runtime certification.
